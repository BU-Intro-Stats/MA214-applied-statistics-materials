\subsection*{Shared Group Workflow}
Use one shared Google Doc for the final report and one shared folder for simulations, data, code, tables, and figures. Assign the four roles below; every member must review the complete submission before it is uploaded.
\begin{itemize}[itemsep=.25em]
  \item \textbf{Member 1 -- Simulation editor:} verify scenarios, code, tables, and plots.
  \item \textbf{Member 2 -- Real-data editor:} verify the model, intervals, diagnostics, and interpretation.
  \item \textbf{Member 3 -- Conclusions lead:} explain the comparison between classical and bootstrap inference and state limitations.
  \item \textbf{Member 4 -- Submission editor:} assemble files, check reproducibility, formatting, and the final shared link.
\end{itemize}

\subsection*{In-Class Work}
\begin{enumerate}[label={\bfseries (\Alph*)},itemsep=.5em]
  \item \textbf{Finalize simulations.} Confirm that all scenarios run reproducibly and that tables or plots summarize the key results.
  \item \textbf{Finalize real-data analysis.} Check the final model, intervals, diagnostics, and interpretation.
  \item \textbf{Write conclusions.} Explain when classical inference worked well, when bootstrap inference helped, and what limitations remain.
  \item \textbf{Submission check.} Confirm that report, code, data, and output files are complete and reproducible.
  \item \textbf{Check-in.} What is your main conclusion about classical versus bootstrap inference?
\end{enumerate}
