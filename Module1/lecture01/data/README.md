# Lecture 1 data

## `2008.csv` (not tracked in git)

This file is the **2008 airline on-time performance data** from the 2009 ASA
Statistical Computing & Graphics Data Expo. It is roughly 657 MB, which exceeds
GitHub's 100 MB per-file limit, so it is excluded via the repository `.gitignore`.

To run the Lecture 1 "big data" demo, download `2008.csv` and place it in this
directory. The dataset is available from the Harvard Dataverse mirror
*"Data Expo 2009: Airline on time data"* (`doi:10.7910/DVN/HG7NV7`), which provides
per-year files `1987.csv`–`2008.csv`.
