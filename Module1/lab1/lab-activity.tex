\section*{Question 3. Compute Summaries}

Use counts and grouped summaries to answer concrete questions about destinations and air time.

\begin{lstlisting}
state_counts <- flights %>%
  count(dest)

air_time_by_month <- flights %>%
  group_by(month) %>%
  summarize(
    mean_air_time = mean(air_time, na.rm = TRUE),
    n_flights = n()
  )
\end{lstlisting}
